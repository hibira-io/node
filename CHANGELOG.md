# Changelog

## 0.1.0

- First release.
- Chat API: `hibira.chat` for conversations, members, messages, read receipts, system messages and a user's conversations.
- Live Chat: `liveChatUserHash()`, `liveChatIdentity()` and `liveChatScriptTag()` for verified visitors, with Express, Koa and Fastify middleware.
- Approvals: `hibira.approvals` (`request`, `get`, `wait`, `reply`) and `verifyApprovalCallback()` for signed `callback_url` deliveries.
